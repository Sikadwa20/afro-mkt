# AfroMkt Capacitor Mobile Preview Setup

This project has been set up with Capacitor so AfroMkt can be previewed like a mobile app.

The current setup is intentionally simple: the Android app opens the live AfroMkt website at:

**https://afro-mkt.com**

That means you can preview the real live site inside a native Android app shell without rebuilding the website locally first.

## What was added

- Capacitor was installed in the project.
- The Android mobile app project was created in the `android/` folder.
- `capacitor.config.json` was configured with:
  - App name: `AfroMkt`
  - App ID: `com.afromkt.app`
  - Live website URL: `https://afro-mkt.com`
- A small `www/index.html` placeholder was added because Capacitor requires a local web folder, even though the app is loading the live website.
- Helpful npm scripts were added to `package.json`.

## Important files and folders

- `capacitor.config.json` — main Capacitor settings.
- `android/` — Android Studio project generated by Capacitor.
- `www/` — small required placeholder folder for Capacitor.
- `package.json` — contains shortcut commands.

## First-time setup on your computer

Before previewing the Android app, install these tools:

1. **Node.js**  
   Download from: https://nodejs.org

2. **Android Studio**  
   Download from: https://developer.android.com/studio

3. **Android SDK**  
   Android Studio normally helps install this during setup.

4. **An Android phone or emulator**  
   - Real phone: enable Developer Options and USB Debugging.
   - Emulator: create one inside Android Studio.

## Install project dependencies

From the project folder, run:

```bash
npm install
```

## Open the Android app in Android Studio

Run:

```bash
npm run cap:open:android
```

This opens the `android/` folder in Android Studio.

From Android Studio:

1. Wait for Gradle to finish syncing.
2. Choose an Android emulator or connected phone.
3. Click the green **Run** button.

The app should open and load **https://afro-mkt.com** inside the mobile shell.

## Run directly from the terminal

If an Android emulator is already running, or a phone is connected, you can run:

```bash
npm run cap:run:android
```

This builds and launches the app on the selected device.

## Build a test APK

To create a debug APK for testing, run:

```bash
npm run android:debug-apk
```

After the build finishes, the APK should be here:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

You can install this APK on an Android phone for testing.

## When the website changes

Because this setup loads the live website, most changes published to **https://afro-mkt.com** will appear in the app automatically.

If you later switch to bundling the website files inside the app, then you would need to run:

```bash
npm run cap:sync
```

For now, the live-site setup is best for quick previewing.

## Next steps before Play Store submission

This setup is only for preview/testing. Before publishing to the Play Store, the app should also have:

1. **A proper app icon** using the AfroMkt logo.
2. **A branded splash screen** for app startup.
3. **Production signing keys** for Android release builds.
4. **A privacy policy URL** for the Play Store listing.
5. **Final testing on real Android phones**.
6. **Optional iOS setup** using Capacitor's iOS platform if you want an iPhone version later.
7. **Store listing assets**, including screenshots, short description, full description, and feature graphic.
